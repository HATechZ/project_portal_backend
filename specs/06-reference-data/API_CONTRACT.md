# API Contract: 06 — Reference Data Domain

There is no umbrella public CRUD route. Public business routes are defined only by 06.1 POL Code, 06.2 POD Code, 06.3 Cargo Codes, and 06.4 Vessel Codes. Shared platform envelopes, UUID validation, Swagger, `x-request-id`, and centralized `AppException`/Prisma error mapping apply.
