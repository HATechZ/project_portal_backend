# SPEC: 07.2 — ETC Document Codes

**Status:** WIP — Gate 4. ETC Document Code is an independent tenant master-data module. Its extendable starter catalogue is `901 | Lesson and Learnt`, `902 | Picture`, `999 | Backup`. Users may add ETC codes later; no 900–999 restriction exists and ownership is explicit, never numeric.

Future list/detail/create/update/active lifecycle behavior uses General Document Code only as a current convention reference and may evolve independently.
